# 🎯 Помощник торговца для Stay Out

Бесплатная программа-оверлей для автоматизации поиска цен на доске объявлений в игре **Stay Out**.

## 📺 Видео-обзор
[Смотреть на YouTube](https://www.youtube.com/watch?v=UphC7xJ84VQ)

## ✨ Возможности
- 🔍 **Поиск предметов** с автодополнением (база берется с so-wiki.ru)
- 📸 **Авто-скриншот цен** — программа вводит название в игру и снимает область с ценами
- 👁 **Всплывающая картинка** при наведении на предмет в списке
- 💾 **Сохранение списка** и скриншотов после перезапуска
- ✏️ **Переименование** и добавление своих предметов
- 🌐 **Быстрый переход на Wiki** по кнопке
- 📌 **Режим оверлея** — окно всегда поверх игры

## 🚀 Установка

### Вариант 1: Готовая сборка (для пользователей)
1. Скачайте `StayOut_Helper.exe` из раздела [Releases](../../releases)
2. Запустите от имени Администратора
3. Пройдите калибровку (наведите мышку на поле поиска и выделите область цен)

### Вариант 2: Запуск из исходников (для разработчиков)
